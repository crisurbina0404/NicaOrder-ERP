Detalle del Calculo

Salario Bruto

Salario Base + Horas Extra + Bonificaciones + Comisiones = Salario Bruto
C$ {{ "%.2f"|format(item.base_salary) }} + C$ {{ "%.2f"|format(item.overtime) }} + C$ {{ "%.2f"|format(item.bonuses) }} + C$ {{ "%.2f"|format(item.commissions) }} = C$ {{ "%.2f"|format(item.gross_salary) }}

INSS Laboral

Salario Bruto x 7% = INSS
C$ {{ "%.2f"|format(item.gross_salary) }} x 0.07 = C$ {{ "%.2f"|format(item.employee_inss) }}

Impuesto a la Renta (Ley 822)

Base Anual = (Salario Bruto - INSS) x 12
(C$ {{ "%.2f"|format(item.gross_salary) }} - C$ {{ "%.2f"|format(item.employee_inss) }}) x 12 = C$ {{ "%.2f"|format(item.annual_taxable_income) }} (anual)
{% if item.tax_bracket %}
Tramo: C$ {{ "%.2f"|format(item.tax_bracket.lower_limit) }} - {% if item.tax_bracket.upper_limit %}C$ {{ "%.2f"|format(item.tax_bracket.upper_limit) }}{% else %}en adelante{% endif %} ({{ item.tax_bracket.excess_percentage }}%)
IR Anual = C$ {{ "%.2f"|format(item.tax_bracket.base_tax) }} + (Exceso x {{ item.tax_bracket.excess_percentage }}%)

Salario Neto
